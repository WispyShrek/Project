◆ care()

void PlantCaretaker::care ( )
overridevirtual

Applies care to the next garden in the queue. Pops the front garden from the queue and calls its applyCare method.

Applies care to gardens. The care function dequeues a garden pointer the from the front of the careQueue member variable and calls applyCare() on the dequeued object. Only one object gets dequeued per function call. When the careQueue is empty the function will have no effect.
