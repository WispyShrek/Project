Detailed Description

Manages a collection of inventory items as strings.

The Inventory class implements the Collection interface for string items, providing functionality to add, remove, and iterate over inventory items. Items are stored in order of addition with no capacity limit.

Removes the first occurrence of an item from the inventory.

Searches for the given item name in the inventory and removes the first matching occurrence. If the item is not found, the function has no effect. If there are duplicate items, only the first one is removed.
