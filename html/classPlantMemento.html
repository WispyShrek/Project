Detailed Description

Stores the internal state of a Plant object.

The PlantMemento is part of the Memento design pattern. It is created by a Plant (the Originator) to save its current state (a PlantState object). The Caretaker can hold this memento and use it to restore the Plant's state later, without having access to the state's implementation details.
