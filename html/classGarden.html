◆ detach()

void Garden::detach ( PlantCaretaker *  staff)

detaches a plantcaretaker from a garden object. The detach function finds and removes the given PlantCaretaker from the list of PlantCaretakers stored in the staffList member variable to be notified of changes to a Garden object. The given PlantCaretaker will no longer be notified of changes to the Garden object. When the function is called on an empty staffList or the given PlantCaretaker object does not exist within the list, the function will have no effect.

Parameters
Apointer to a PlantCaretaker object.
