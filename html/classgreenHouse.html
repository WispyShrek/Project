Detailed Description

A class representing a greenhouse that holds a 3x3 grid of plants.

The greenHouse class inherits from the Collection<Plant*> class and implements methods to manage a 3x3 grid of Plant pointers, including adding, removing, and iterating over the plants in the greenhouse.
