# Project
a Game that allows players to manage their own nursery. The game includes different plant types, that each have their own needs, different gardens and greenhouses as well as staff to lend a helping hand. 

# Playing the game
Compile the program by typing "make" into the terminal. 
Run the program by typing "make run" into the terminal.
To run unit testing, type "make test" into the terminal.
