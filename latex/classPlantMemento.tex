\doxysubsection{Detailed Description}
Stores the internal state of a \mbox{\hyperlink{classPlant}{Plant}} object. 

The \mbox{\hyperlink{classPlantMemento}{Plant\+Memento}} is part of the Memento design pattern. It is created by a \mbox{\hyperlink{classPlant}{Plant}} (the Originator) to save its current state (a \mbox{\hyperlink{classPlantState}{Plant\+State}} object). The \mbox{\hyperlink{classCaretaker}{Caretaker}} can hold this memento and use it to restore the \mbox{\hyperlink{classPlant}{Plant}}\textquotesingle{}s state later, without having access to the state\textquotesingle{}s implementation details.
