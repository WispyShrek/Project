\doxysubsection{Detailed Description}
\mbox{\hyperlink{classIterator}{Iterator}} for traversing a collection of inventory item strings. 

This iterator provides bidirectional traversal over a std\+::vector$<$std\+::string$>$ with standard operations to get the current item, move to the first/next/previous elements, and query completion.
