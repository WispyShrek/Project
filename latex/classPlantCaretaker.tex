Applies care to the next garden in the queue. Pops the front garden from the queue and calls its apply\+Care method. 

Applies care to gardens. The care function dequeues a garden pointer the from the front of the care\+Queue member variable and calls apply\+Care() on the dequeued object. Only one object gets dequeued per function call. When the care\+Queue is empty the function will have no effect.
