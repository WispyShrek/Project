\doxysubsection{Detailed Description}
Manages a collection of inventory items as strings. 

The \mbox{\hyperlink{classInventory}{Inventory}} class implements the \mbox{\hyperlink{classCollection}{Collection}} interface for string items, providing functionality to add, remove, and iterate over inventory items. Items are stored in order of addition with no capacity limit.
