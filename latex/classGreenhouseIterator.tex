\doxysubsection{Detailed Description}
\mbox{\hyperlink{classIterator}{Iterator}} for traversing a collection of \mbox{\hyperlink{classgreenHouse}{green\+House}} pointers. 

This iterator provides bidirectional traversal over a std\+::vector$<$green\+House$\ast$$>$ with standard operations to get the current item, move to the first/next/previous elements, and query completion.
