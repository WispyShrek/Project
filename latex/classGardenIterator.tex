\doxysubsection{Detailed Description}
\mbox{\hyperlink{classIterator}{Iterator}} for traversing a collection of \mbox{\hyperlink{classGarden}{Garden}} pointers. 

This iterator provides bidirectional traversal over a std\+::vector$<$\+Garden$\ast$$>$ with standard operations to get the current item, move to the first/next/previous elements, and query completion.
