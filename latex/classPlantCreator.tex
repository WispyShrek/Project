\doxysubsection{Detailed Description}
An abstract factory class for creating \mbox{\hyperlink{classPlant}{Plant}} objects. 

The \mbox{\hyperlink{classPlantCreator}{Plant\+Creator}} class defines the interface for creating \mbox{\hyperlink{classPlant}{Plant}} instances. Subclasses must implement the create\+Plant method to instantiate specific \mbox{\hyperlink{classPlant}{Plant}} types.
