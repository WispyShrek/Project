\doxysubsection{Detailed Description}
A controller class for managing greenhouse systems like sprinklers and lights. 

The \mbox{\hyperlink{classGreenhouseController}{Greenhouse\+Controller}} class uses the \mbox{\hyperlink{classCommand}{Command}} design pattern to encapsulate requests to turn on/off sprinklers and lights in the greenhouse.
